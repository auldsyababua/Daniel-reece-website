# Task Status Alternatives

If emojis are not rendering correctly in your terminal or editor, you can use these alternatives:

## Option 1: Unicode Emojis (Default)
- ⬜ Not Started
- 🟨 In Progress  
- ✅ Completed
- ❌ Blocked
- 🔄 Needs Revision

## Option 2: ASCII Symbols
- [ ] Not Started
- [~] In Progress
- [x] Completed
- [!] Blocked
- [<>] Needs Revision

## Option 3: Text Labels
- [TODO] Not Started
- [WIP] In Progress
- [DONE] Completed
- [BLOCKED] Blocked
- [REVIEW] Needs Revision

## Option 4: Markdown Checkboxes
- [ ] Not Started
- [ ] 🕸 In Progress (partially checked)
- [x] Completed
- [-] Blocked (strikethrough)
- [~] Needs Revision

## To Fix Broken Emojis

Run the emoji fix script:
```bash
.claude/ai-dev/kiro/emoji-fix.sh
```

Or manually replace in your tasks.md file using your editor's find/replace feature.
