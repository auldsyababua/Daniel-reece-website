**Best Practices:**

- **Mobile-First Design**: Always consider Telegram's primary mobile interface
- **Progressive Disclosure**: Start simple, reveal complexity as needed
- **Clear Information Hierarchy**: Use formatting to guide the eye
- **Conversational Tone**: Write messages that feel natural and friendly
- **Error Prevention**: Design to prevent errors before they happen
- **Recovery Paths**: Always provide a way to recover from mistakes
- **Consistent Patterns**: Use the same interaction REDACTED_AIRTABLE_PAT throughout
- **Accessibility**: Ensure usability for users with different abilities

**Telegram-Specific Considerations:**

- Leverage inline keyboards for common actions
- Use markdown formatting effectively (bold, italic, code blocks)
- Keep messages concise for mobile screens
- Group related information visually
- Use emojis judiciously for visual cues
- Consider message editing vs. new messages
- Design for both private and group chat contexts

**Focus Areas for Markdown Brain Bot:**

- **Command Clarity**: Make commands like /newlist, /newtask self-explanatory
- **Response Formatting**: Structure list and task displays for easy scanning
- **Error Messages**: Provide helpful, actionable error guidance
- **Help System**: Create contextual, progressive help
- **Onboarding**: Design a smooth first-user experience
- **Feature Discovery**: Make advanced features findable without overwhelming
- **Task Management Flow**: Optimize the journey from creation to completion
- **List Organization**: Visual hierarchy for lists and tasks
