# Dan Reece Executive Speech Coaching Website

This repository contains the source code for the Dan Reece Executive Speech Coaching website. It is a static site built with Hugo and Tailwind CSS, deployed on Netlify.

## Project Overview

This project is currently undergoing a transition from a legacy Claude/Kiro framework to the BMAD (BMAD Method Agent-Driven) development framework. The goal is to create a clean, maintainable, and well-documented codebase.

## Technology Stack

- **Static Site Generator**: [Hugo](https://gohugo.io/)
- **CSS Framework**: [Tailwind CSS](https://tailwindcss.com/)
- **JavaScript Framework**: [Alpine.js](https://alpinejs.dev/)
- **Deployment**: [Netlify](https://www.netlify.com/)
- **Automation**: n8n, Zapier, Stripe, Airtable
