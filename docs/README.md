# Dan Reece Executive Speech Coaching Website

This repository contains the source code for the Dan Reece Executive Speech Coaching website. It is a static site built with Hugo and Tailwind CSS, deployed on Cloudflare Pages with a Cloudflare-first architecture.

## Project Overview

This project is built using the BMAD (BMAD Method Agent-Driven) development framework. The goal is to create a clean, maintainable, and well-documented codebase with modern serverless architecture.

## Technology Stack

- **Static Site Generator**: [Hugo](https://gohugo.io/) (v0.128.0+)
- **CSS Framework**: [Tailwind CSS](https://tailwindcss.com/) (v4.0+)
- **JavaScript Framework**: [Alpine.js](https://alpinejs.dev/) (v3.x)
- **Hosting**: [Cloudflare Pages](https://pages.cloudflare.com/)
- **Serverless Functions**: [Cloudflare Workers](https://workers.cloudflare.com/)
- **Database**: [Cloudflare D1](https://developers.cloudflare.com/d1/) (SQLite-compatible)
- **Admin Interface**: [D1 Manager](https://github.com/JacobLinCool/d1-manager)
- **Automation**: [n8n Cloud](https://n8n.io/), integrated via Cloudflare Workers
